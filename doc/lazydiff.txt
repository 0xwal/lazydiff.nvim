1. INTRODUCTION                                         *lazydiff-introduction*

lazydiff renders the diff between the buffer and a baseline revision
(default `HEAD`) in place, using extmarks: deleted lines appear as red
virtual lines above their old position, added lines get a `+` in the sign
column and a coloured band, and a `@@ -a,b +c,d @@` header sits above each
hunk. The buffer stays editable; the overlay repaints as you type.

The ref is a baseline. The plugin compares the working tree against that
revision; it never shows the change the revision introduced.

- git backend: `git diff <ref>`; the baseline blob is `git show <ref>:path`.
- jj backend: `@`, an empty ref and `HEAD` name the working-copy commit, so
  the baseline is its first parent, `first_parent(@)` = `@-`. Any other
  ref, for example `@-` or a change id, is used verbatim as the baseline.

So `:LazydiffQf @-` lists the uncommitted changes since the previous
commit. See |:LazydiffQf|.

==============================================================================
2. REQUIREMENTS                                         *lazydiff-requirements*

- Neovim 0.10 or newer
- `git` on `$PATH`, or `jj` for a jj repository; the `.jj` marker selects
  that backend

3. COMMANDS                                                 *lazydiff-commands*

                                                                   *:Lazydiff*
:Lazydiff [{ref}]
    Toggle the overlay on the current buffer. With {ref}, diff against that
    ref instead of |lazydiff-config| `ref`. Running it again with the same
    ref turns the overlay off; a bare `:Lazydiff` turns off whatever ref is
    active. {ref} completes against branches and tags.

    Toggling on a file with no changes keeps the overlay armed: it paints as
    soon as the buffer diverges from the baseline.

                                                                *:LazydiffOff*
:LazydiffOff
    Disable the overlay on the current buffer.

                                                            *:LazydiffRefresh*
:LazydiffRefresh
    Refetch the baseline blob from git and re-render.

                                                           *:LazydiffNext*
                                                           *:LazydiffPrev*
                                                          *:LazydiffFirst*
:LazydiffNext [{mode}]
:LazydiffPrev
:LazydiffFirst
    Move the cursor between hunks. `]h` / `[h` wrap when `nav.wrap` is set.
    {mode} is `buffer` (default), which walks this buffer's hunks, or
    `all`, which continues into the hunks of the other changed files.

                                                              *:LazydiffReset*
:LazydiffReset
    Put the baseline's lines back in place of the hunk under the cursor.
    On an added block this deletes it; on a deleted block it reinserts the
    red lines. Nothing changes and a WARN message is shown when:
      - the buffer is not enabled by lazydiff
      - the review pane is read-only (external)
      - there is no baseline for the file
      - the file is untracked, so there is nothing to revert to
      - the buffer is not modifiable
      - there is no hunk under the cursor

                                                               *:LazydiffYank*
:LazydiffYank [{register}]
    Yank the deleted lines of the hunk under the cursor, linewise, into
    {register} (default the unnamed register). Virtual lines cannot be
    yanked with `y`; this is the way to copy them.

                                                              *:LazydiffFloat*
:LazydiffFloat [{ref}]
    Toggle the float over every file differing from {ref} (or the
    configured `ref`) plus untracked files. See |lazydiff-float|.

                                                           *:LazydiffFloatOff*
:LazydiffFloatOff
    Close the float.

                                                             *:LazydiffStart*
:LazydiffStart [{ref}]
    Start a session. A buffer entered while the session is active gets the
    overlay when its file differs from {ref} or, without {ref}, from the
    configured `ref`. |:LazydiffStop| ends the session.

                                                              *:LazydiffStop*
:LazydiffStop
    End the session and disable the overlays it enabled. A ref passed to
    |:LazydiffStart| is not reset, so a later |:LazydiffQf| without an
    argument keeps using it.

                                                                 *:LazydiffQf*
:LazydiffQf [{ref}]
    Fill the quickfix list with one item per hunk of the working tree
    against {ref}, and open it. No |:LazydiffStart| session is needed. The
    ref order is: {ref}, then the session ref, then the configured `ref`.
    Items for paths that are not regular files, or that cannot be read,
    carry `valid = 0`, so `:cc` and `:cn` skip them. When a changed path
    has no baseline blob, the plugin prints one warning that names up to
    three such paths.

                                                             *:LazydiffSearch*
    :LazydiffSearch [{ref}]
    Open a floating picker that lists the changed files of the working tree
    against {ref}. Ref order: {ref}, then the session ref, then the configured
    `ref`. The first line is a prompt; typing filters the list by a
    case-insensitive substring of the path. Rows show `+added -deleted`,
    `dir` for directories, `bin` for binary files, or `big` for files over
    5000 lines or 1 MB (not diffed). Keys in the prompt:
    `<CR>` open the selected file, `<C-n>` or `<Down>` next row, `<C-p>` or
    `<Up>` previous row, `<Esc>` close. Leaving the window closes the picker.
    At most 500 files are listed; the rest are counted in a `... N more` row.

==============================================================================
4. FLOAT MODE                                                  *lazydiff-float*

A lazygit-style popup: the changed-file list on the left, the selected file
rendered full-length with the overlay on the right. The list is a snapshot;
press `R` to refresh it. The selection is restored by path.

Keys (configurable via `float.keys`):

  `j` / `k`        select file (sidebar)
  `<CR>`           close the float and open the file with the overlay on
  `]h` / `[h`      next / previous hunk (pane)
  `]f` / `[f`      next / previous file
  `<Tab>`          fold unchanged context, leaving `float.context_lines`
                   around each hunk
  `R`              refresh
  `<C-l>` / `<C-h>` move focus between sidebar and pane
  `q` / `<Esc>`    close

The pane is read-only. Binary files show a placeholder. Renames are listed
once under the new path.

5. LUA API                                                       *lazydiff-api*

All `bufnr` arguments default to the current buffer (nil or 0).
>lua
  require("lazydiff").setup(opts)
  require("lazydiff").toggle(bufnr, ref)
  require("lazydiff").enable(bufnr, ref)
  require("lazydiff").disable(bufnr)
  require("lazydiff").refresh(bufnr, { baseline = true })
  require("lazydiff").is_enabled(bufnr)
  require("lazydiff").goto_first(bufnr)
  require("lazydiff").goto_next(bufnr)
  require("lazydiff").goto_prev(bufnr)
  require("lazydiff").reset_hunk(bufnr)
  require("lazydiff").yank_hunk(bufnr, register)
  require("lazydiff").status(bufnr)      -- { ref, hunks, current } or nil
  require("lazydiff").statusline(bufnr)  -- "lazydiff: hunk 2/5" or ""
  require("lazydiff").toggle_float({ ref = "main" })
  require("lazydiff").open_float({ ref = "main" })
  require("lazydiff").close_float()
<

6. CONFIGURATION                                              *lazydiff-config*

Defaults:
>lua
  require("lazydiff").setup({
    ref = "HEAD",
    vcs = "auto",
    signs = { add = "+", delete = "- " },
    show_hunk_header = true,
    show_author_header = false,
    show_commit_header = false,
    word_diff = true,
    read_only = false,
    auto_refresh = true,
    live_refresh = true,
    debounce_ms = 100,
    watch_git = true,
    force_signcolumn = true,
    jump_on_enable = true,
    nav = { wrap = true, center = true },
    float = {
      width = 0.9,
      height = 0.9,
      sidebar = 0.3,
      border = "rounded",
      title = " lazydiff ",
      number = true,
      select_debounce_ms = 40,
      fold_context = false,
      context_lines = 3,
      keys = {
        close = { "q", "<Esc>" },
        refresh = "R",
        open_file = "<CR>",
        next_hunk = "]h",
        prev_hunk = "[h",
        next_file = "]f",
        prev_file = "[f",
        toggle_fold = "<Tab>",
        focus_list = "<C-h>",
        focus_pane = "<C-l>",
      },
    },
  })
<
`ref`               Ref the working tree is diffed against.
`vcs`               Backend to use: `auto` picks by the `.jj` / `.git`
                    marker nearest the buffer, `git` and `jj` force one and
                    skip detection entirely.
`signs.add`         Sign-column marker on added lines (max 2 cells).
`signs.delete`      Prefix on the virtual lines showing deleted content.
`show_hunk_header`  Show `@@ -a,b +c,d @@` above each hunk.
`show_author_header`
                    Append the baseline's author to the header line, as
                    `author: Jane Doe · Aug 3 2025 (6 months ago)`. The
                    date is the baseline revision's author date. The
                    relative part is English and is refreshed on each
                    render, cached for at most 60 seconds; jj supplies the
                    age phrase itself. The three options are independent: hunk
                    header on and author on puts the author text after the
                    `@@` text on the same line; hunk header off and author
                    on puts the author text alone; all off drops the
                    header line. A nil author, or an unreadable date,
                    leaves the name only, or no header line. The commit
                    header adds its text after the author text; see
                    `show_commit_header`.
`show_commit_header`                                    *show_commit_header*
                    Append the baseline's short commit id and the first
                    line of its message to the header line, after the
                    author text, separated by two spaces. jj shows
                    `change uyknllow  bump version`; git shows
                    `commit 79ed13f  bump version`. The commit is the
                    baseline commit, the same revision the author comes
                    from. An empty message shows `(no description)`. The
                    option is independent of `show_author_header` and
                    `show_hunk_header`. Both backends support it.
`word_diff`         Emphasise changed words inside change hunks whose lines
                    pair up one-to-one.
`read_only`         Lock the buffer while the overlay is on.
`auto_refresh`      Repaint (and refetch the baseline) on |BufWritePost|,
                    |FileChangedShellPost| and |BufReadPost|.
`live_refresh`      Repaint on |TextChanged| / |TextChangedI|, debounced by
                    `debounce_ms`.
`watch_git`         Watch the git directory and refetch the baseline when
                    HEAD or the index change, so commits and checkouts made
                    outside Neovim show up.
`force_signcolumn`  Set 'signcolumn' to `yes:1` in the window while the
                    overlay is on if it was `no`, restoring it on disable.
`jump_on_enable`    Move to the first hunk when toggling on.
`nav.wrap`          `]h` / `[h` wrap around.
`nav.center`        Centre the cursor (`zz`) after a jump.
`float.*`           Geometry, border, title, keys; `select_debounce_ms`
                    delays rendering until the sidebar cursor settles;
                    `fold_context` starts the pane folded; `context_lines`
                    is the visible margin around each hunk when folded.

`setup()` validates option types and raises on a mismatch.

7. HIGHLIGHT GROUPS                                       *lazydiff-highlights*

All groups are defined with `default = true`; user definitions win. They
are derived from `DiffAdd`, `DiffDelete`, `Function` and `Normal` and
re-applied on |ColorScheme|.

  LazydiffAdd          bg of DiffAdd; bg-only so syntax colours survive
  LazydiffDelete       fg + bg of DiffDelete (virtual lines)
  LazydiffAddWord      changed span on an added line
  LazydiffDeleteWord   changed span on a deleted virtual line
  LazydiffAddSign      the `+` sign
  LazydiffDeleteSign   the `- ` prefix
  LazydiffHunkHeader   the `@@` line and the author text; links to
                       `Comment`; set the `highlights.hunk_header` slot to
                       override it

Float mode: LazydiffStatusModified, LazydiffStatusAdded,
LazydiffStatusDeleted, LazydiffStatusRenamed, LazydiffStatusUntracked,
LazydiffCountAdd, LazydiffCountDelete, LazydiffFloatPath, LazydiffFloatDim,
LazydiffFloatTitle, LazydiffFloatSelected, LazydiffFold.

==============================================================================
8. HEALTH                                                     *lazydiff-health*

`:checkhealth lazydiff` verifies the Neovim version, probes each backend
(`git`, `jj`) on `$PATH`, reports the repository the current buffer
resolves to, and checks that the configuration validates.

==============================================================================
9. KNOWN LIMITATIONS                               *lazydiff-limitations*

- The jj backend does not list untracked paths when `snapshot.auto-track`
  excludes them, or after `jj file untrack`.
- Merges diff against the first parent.
- The float pane renders neither syntax highlighting nor the author
  or commit header.
